## 抜き出し手順（全体を埋めるとき）
参照LPを上から見て、セクションごとに1行ずつ表に書く。文言は写さない（構成と見せ方だけ抜く）。

| # | 役割 | レイアウト | 強調の使い方 | CTA |
|---|---|---|---|---|
| B01 | 例: FV | 例: 全幅画像＋キャッチ重ね | 例: キャッチのみ大 | 例: なし |
| B02 | | | | |

役割の語彙: FV／問題提起／共感／原因／解決策の提示／講師・主催者紹介／実績・証拠／お客様の声／内容（カリキュラム）／特典／価格・オファー／保証／限定・締切／FAQ／追伸／CTA

## あわせて書き出す項目
- **幅と余白**: 本文の最大幅、セクション間の余白、スマホでの左右余白
- **文字**: 本文サイズ・行間、見出しの階層（いくつの段階があるか）
- **強調**: 太字／色文字／マーカー／囲み枠／吹き出しのどれを・どこで使うか
- **CTA**: 何回出るか、どのブロックの後か、ボタンの形（角丸・影・幅）、ボタン上下の一言
- **画像**: 文字入り画像（見出し画像）か、HTMLテキストか
- **区切り**: セクションの区切り方（背景色交互・斜め・線・アイコン）

## 固定とするもの／毎回決めるもの
- **固定（この型に従う）**: ブロックの順序の考え方、幅・余白、文字の階層、強調のルール、CTAの出し方
- **毎回ヒアリング**: ファーストビュー、カラーリング、アニメーション、写真素材（→ `hearing.md`）
