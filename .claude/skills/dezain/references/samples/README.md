# 見本の一覧

デザインの見本LPを1本ずつ記録する。**写すのは構成と見せ方だけ**（文言・写真・ロゴは使わない）。

| ID | 見本 | 向いている案件 | 土台への取り込み |
|---|---|---|---|
| tac9th | The Authors' Club 第9期募集（ https://ipspub.com/lp/tac9th/ ） | 講座・塾・コミュニティの募集。実績と声で畳みかける長尺 | 済（2026-10-01・初版の土台） |

## 見本の足し方
1. **実測する**: スマホ390px・PC1280pxでページ全体のスクショを撮り、HTML・CSS・JSを読む（Claude in Chrome、またはこのクラウド環境＋ネットワーク許可）
2. **`samples/<ID>.md` を作る**: `tac9th.md` と同じ形で
   - 上から順の骨格表（役割・背景・レイアウト）
   - CTAの出し方
   - 動き（何が・どう・何秒）
   - テキストの見せ方（強調の種類と使い分け）
   - 色・書体の実測値
3. **土台と比べる**: 新しい見せ方を3つに分ける
   - 土台と同じ → 何もしない
   - 今後も使いたい → `kit/base.css`・`kit/base.js` に部品やクラスとして足し、`design-base.md` の表に1行足す。`kit/demo.html` にも置いて動作を確認する
   - その見本だけの味 → `samples/<ID>.md` に残すだけ。使う時は指示書で「見本◯◯の△△」と指定する
4. **この一覧に1行足す**
5. 土台を変えた場合は、既存の部品の見た目が変わっていないか `kit/demo.html` で確かめる（クラス名は変えない。変えるなら古い名前も残す）
