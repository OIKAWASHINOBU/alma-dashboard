# デザインの土台（全案件共通）

見本（`samples/`）から「いつも使う見せ方」を抜き出して固定したもの。**動き・テキストの見せ方・部品はこの土台に従う。** 実体は `kit/base.css`・`kit/base.js`、使い方の見本は `kit/demo.html`。

- 土台の出典: `samples/tac9th.md`（2026-10-01 初版）
- 見本を足したら → `samples/README.md` の手順で、この土台と kit に取り込む

## 毎回決めるもの／決めないもの

| 区分 | 項目 | 決め方 |
|---|---|---|
| **土台（毎回は聞かない）** | アニメーション、フェードイン、テキストの強調、見出しの段階、余白、部品 | このファイルと kit のとおり。外したい・足したい時だけ指示書に書く |
| **毎回ヒアリング** | 色（`:root` の変数）、FV（何を一番大きく見せるか）、CTAの出し方、写真素材、使う見本 | `hearing.md` |

## 動き（アニメーション）

| 動き | クラス | 値 | 使う場所 |
|---|---|---|---|
| FVの登場 | `fv-in`（ボタンは `fv-in fv-in--btn`） | 上から10px（ボタンは30px）、1秒、書いた順に0.8秒ずつずらす | FVのラベル→実績の一行→キャッチ→サブ→写真→ボタン |
| ふわっと上がる | `fx-up` | 下20px→0、0.75秒 ease-out | 既定。カード・段落のまとまり・画像・動画 |
| 左右から滑り込む | `fx-left` / `fx-right` | 横20px→0、0.75秒 | 数字カードや推薦の声を**左右交互**に |
| その場でフェード | `fx-fade` | 1秒 | 区切りタイトル、手紙、申込欄、大きな写真 |
| 白い幕が抜ける | `fx-mask` | 0.8秒 linear | 見出し画像・写真のアクセント（1区切りに1回まで） |
| ずらし | `d1`〜`d5` | 0.3秒刻み | 横に並ぶ同じ部品だけ |
| 横に流れる帯 | `marquee` | 等速・止まらない | 書影・ロゴ・旗・実績の写真 |
| 固定の申込ボタン | `follow` | 1500pxスクロール後に上から出る | ページに1つ |
| ページ内リンク | 自動 | なめらかに・上40px空ける | ナビ・FVボタン |

**きっかけ**: 要素が画面の下30%に入ったら一度だけ動く（戻しても再生しない）。
**守ること**: 文字が読めない時間を作らない／`prefers-reduced-motion` の人には動かさない（kit が自動で止める）／1画面で同時に動くのは3つまで。

## テキストの見せ方

| 見せ方 | クラス | ルール |
|---|---|---|
| 黄マーカー＋太字 | `mk` | 読み飛ばされても伝えたい一文。**1段落に1か所まで** |
| 下線＋太字 | `ul` | 主張の言い切り |
| メイン色の太字 | `c-main` | 名前・ラベル・数字 |
| 赤・大きく | `big-alert` | **ページ全体で1〜2か所**（最大の実績数字） |
| 一言見出し（“ ”） | `quote-head` | 推薦の声の見出し |
| 吹き出し | `bubble` | お客様の声の見出し |
| 便箋 | `letter` | 主催者の手紙 |

**見出しの段階**: 区切りタイトル `sec-title`（英字・頭文字だけメイン色＋日本語ラベル＋線）＞ 中央の小見出し `h-center` ＞ 項目見出し `h-item`（メイン色）/ `h-bold` ＞ 本文。
**本文**: スマホ15px・PC18px、行間1.8、字間やや広め、段落の間は1行空ける。FVのキャッチと手紙は明朝。

## 区切りと余白
- 区切りは背景色を切り替えて示す（`sec--beige` / `sec--gray` / `sec--pale` / `sec--main`）。同じ背景を2つ続けない
- 区切りの上下はスマホ64〜80px、PC100px前後。本文幅はPC800px、スマホは左右20px
